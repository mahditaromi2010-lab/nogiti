# گزارش راستی‌آزمایی بستهٔ Nugiti

تاریخ بررسی: 2026-10-22

## نسخه و دارایی‌ها

- مبنا: `Nogiti-admin-security-branding-update.zip` تولیدشده در همین گفت‌وگو؛ بستهٔ برندینگ `Nogiti-branding-kit.zip` فقط برای تطبیق لوگو و آیکون استفاده شده است.
- نسخهٔ اصلاح‌شده: `Nugiti-admin-security-final-verified.zip`.
- فایل‌های لوگو و آیکون در آرشیو با فایل‌های نسخهٔ کاری تطبیق بایتی دارند.
- آرشیو از نظر ساختار ZIP بررسی شده و خطای CRC یا ورودی خراب گزارش نشده است.

## بررسی‌هایی که اجرا شدند

- `npm run check` — موفق؛ بررسی نحوی سرور، ماژول امنیت مدیر، اسکریپت‌های مهاجرت و ایجاد مدیر، JavaScript عمومی و تست‌ها.
- `node --test` — پس از اصلاح مهاجرت مدیران، ۷ تست موفق و ۰ ناموفق.
- بررسی ایستای مسیرهای ثبت‌شدهٔ `/admin/**` — مسیرهای مدیریتی غیر از صفحهٔ ورود باید `requireAdmin` داشته باشند.
- اصلاح مهاجرت حساب‌های مدیریتی قدیمی: فقط یک حساب فعالِ اول به نقش `owner` ارتقا می‌یابد و سایر حساب‌های قدیمی نقش محدودتر `admin` می‌گیرند؛ این رفتار با تست واحد پوشش داده شده است.
- بهبود UI پنل: وضعیت فعال آیتم منو، `aria-current`, حلقهٔ فوکوس صفحه‌کلید و قواعد واکنش‌گرایی در عرض‌های کم اضافه شده‌اند.
- بررسی فایل‌های آرشیو برای `.env`، کلید خصوصی، الگوهای رایج توکن و رمزهای آشکار — موردی پیدا نشد.
- تأیید وجود لوگوی WebP، faviconها، آیکون موبایل و `site.webmanifest`.

## محدودیت‌ها

- وابستگی‌ها در این محیط نصب نشده‌اند؛ بنابراین اجرای کامل برنامه، lint/build وابسته به ابزارهای اضافی و آزمون HTTP واقعی انجام نشده است.
- PostgreSQL/Docker در دسترس آزمون نبودند؛ SQL migration، ورود/خروج با نشست واقعی و عملیات CRUD متصل به پایگاه داده end-to-end تأیید نشده‌اند.
- `package-lock.json` در بسته وجود ندارد؛ برای استقرار قابل‌تکرار باید lockfile را در محیط دارای دسترسی سالم به npm تولید و بررسی کرد.
- تلاش برای ارتباط Git با `github.com` از محیط ساخت با خطای DNS (`Could not resolve host`) مواجه شد. در این مرحله هیچ commit یا push واقعی انجام نشده است.

## نتیجه

این بسته، نسخهٔ کد اصلاح‌شده و بررسی‌شده در سطح نحوی/واحدی است؛ آزمون یکپارچهٔ عملیاتی، رندر واقعی قالب‌های EJS در مرورگر، آزمون دیتابیس و انتشار در GitHub هنوز تأیید نشده‌اند. موفقیت تست‌های فعلی به معنی تضمین نبود آسیب‌پذیری یا آمادگی قطعی برای محیط production نیست.
